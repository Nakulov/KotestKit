Новый артефакт `kotestkit-serialization`: тесты соответствия JSON и DTO на kotlinx.serialization. Ядро `kotestkit` не менялось, переход с 2.0.0 ничего не требует.

Подключение, флаги `DefaultTestJson` и примеры описаны в [README](https://github.com/Nakulov/KotestKit/blob/v2.1.0/README.md#json-и-dto).

## Подключение

```kts
plugins {
    kotlin("plugin.serialization") version "<версия Kotlin проекта>"
}

dependencies {
    testImplementation("io.github.nakulov:kotestkit-serialization:2.1.0")
    implementation("org.jetbrains.kotlinx:kotlinx-serialization-json:1.9.0")
}
```

`kotlinx-serialization-json` артефакт не приносит: версию выбирает проект, не ниже 1.9.0. Ядро `kotestkit` приходит вместе с ним.

## Новое

- `withJson { ... }` в корне `BehaviorSpec` — группа тестов сериализации. Свой `Json` передаётся параметром, по умолчанию `DefaultTestJson`.
- `shouldDecodeTest(resource, expected)` — образец из ресурсов → DTO, сравнение через `shouldBe`. Имя теста: `dto/user/full.json -> UserDto`.
- `shouldEncodeTest(value, resource)` — DTO → образец, сравнение через `shouldEqualJson`: порядок ключей и пробелы не важны.
- Внутри `withJson` другие способы создать тест не компилируются, `withJson` в контейнере и в тесте — тоже.
- При падении первой в стеке идёт строка вызова в вашей спеке.

```kotlin
class UserDtoTest : BehaviorSpec({
    withJson {
        shouldDecodeTest("dto/user/full.json", UserDto(1, "Аня", "anya"))
        shouldEncodeTest(UserDto(1, "Аня", "anya"), "dto/user/full.json")
    }
})
```
